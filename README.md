# Pizza Order Form

A semantic HTML web form for submitting a pizza order, built as part of a web development course. Validated using the W3C Markup Validation Service.

## Features

**Order Form**
- Required fields: name, phone, email, pizza size, and sauce type — form will not submit unless all are filled
- Pizza size dropdown with Medium, Large, and XLarge options
- 6+ topping checkboxes for customization

**Favorite Video Games Table**
- Displays a table of favorite video games
- Includes at least one vertically and one horizontally merged cell
- Built with semantic HTML table elements

## Requirements Met
- Full client-side form validation on required fields
- Semantic HTML throughout
- No errors found by the W3C Markup Validator
- Deployed and accessible via GitHub Pages
